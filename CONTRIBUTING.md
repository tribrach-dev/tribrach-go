# Contributing

tribrach-go follows the contribution rules of the core project:
see [tribrach/CONTRIBUTING.md](https://github.com/tribrach-dev/tribrach/blob/main/CONTRIBUTING.md).

- Sign every commit (`git commit -s`, Developer Certificate of Origin).
- Behaviour shared with other instruments (annotation grammar, drift
  outcomes, replay comparison) is defined by the core conformance cases. If
  you think one is wrong, open an issue on the core repository.
- Go-specific checks and diagnostics (`TRG…` codes) are decided here.
